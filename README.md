# mds.by — статическая версия сайта

Полная статическая копия сайта [mds.by](https://mds.by) (MDS — детейлинг-центр в Минске), выгруженная из Tilda. Работает без конструктора Tilda и её CDN: все картинки, стили, скрипты, шрифты и анимации лежат в репозитории.

## Что внутри

| Путь | Содержимое |
|---|---|
| `index.html`, `price/`, `about/`, `services/…` | 27 страниц из `sitemap.xml` + 17 страниц постов и кейсов (`…/tpost/…`) |
| `assets/img/` | все изображения (оригиналы и миниатюры) |
| `assets/tilda/` | CSS/JS рантайма Tilda (анимации, Zero-блоки, слайдеры, попапы, формы) и бандлы стилей каждой страницы |
| `assets/fonts/` | шрифты (Inter, Tilda Sans) |
| `**/feeds/*.json` | снимки лент блога, работ и кейсов (раньше грузились из API Tilda) |
| `robots.txt`, `sitemap*.xml`, `llms*.txt` | SEO-файлы без изменений |
| `tools/` | скрипты, которыми сделана выгрузка (можно перезапустить после правок в Tilda) |

### SEO
Без изменений сохранены `<title>`, `description`, Open Graph, `canonical` (абсолютные URL `https://mds.by/...`), JSON-LD, `alt` у картинок, Яндекс.Метрика и Google Tag Manager. URL страниц совпадают с текущими, так что после переезда домена ссылки в поисковиках не сломаются.

### Ссылки
Внутренние ссылки относительные: сайт открывается и с корня домена, и из подпапки (например, GitHub Pages `user.github.io/mds-by/`).

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Через `file://` сайт не заработает: ленты подгружают JSON через XHR, а для этого нужен веб-сервер.

## Деплой

Подойдёт любой статический хостинг: GitHub Pages, Netlify, Cloudflare Pages, nginx. Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root. Файл `.nojekyll` уже лежит в корне: без него Jekyll пропустит папки, имена которых начинаются с `_`.

Свой домен: добавьте файл `CNAME` с содержимым `mds.by` и укажите DNS-записи по документации хостинга.

## Что ещё зависит от внешних сервисов

- **Формы заявок** (4 страницы) отправляются в обработчик форм Tilda (`forms.tildacdn.com`). Пока проект в Tilda активен, заявки приходят как раньше. При полном отказе от Tilda замените обработчик на свой (Formspree, Telegram-бот, свой backend).
- **Яндекс.Карта** на контактах, **Метрика** и **GTM** подключаются со своих серверов, как и раньше.
- **Ленты** (блог, работы, кейсы) — это снимок на дату выгрузки. Чтобы обновить их после публикации новых постов в Tilda, перезапустите скрипт:
  ```bash
  python3 tools/feeds.py . /tmp/mds-cache
  ```

## Повторная выгрузка

```bash
python3 tools/mirror.py tools/urls.txt . /tmp/mds-cache   # tools/urls.txt — список URL страниц из sitemap
python3 tools/feeds.py . /tmp/mds-cache
```
